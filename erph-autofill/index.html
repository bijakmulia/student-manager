ERPH Autofill

Isi borang ERPH GURU (AppSheet) secara automatik — ikut jadual waktu anda, cadangkan SK seterusnya, dan tulis objektif, aktiviti & refleksi dengan bantuan AI.

⚠️ Khas untuk pengguna eRPH jenis AppSheet Skrip ini hanya berfungsi pada aplikasi ERPH GURU yang dibuka di appsheet.com. Jika sekolah anda guna sistem eRPH lain (contoh DELIMa / borang lain), skrip ini tidak akan berfungsi — guna eRPH Pintar sebagai ganti.

Apa yang ia buat

🗓️Ikut jadual waktuTunjuk kelas seterusnya yang belum diisi minggu ini.
⭐Cadang SK seterusnyaIngat SK terakhir setiap kelas — tak perlu skrol dropdown.
🤖Prompt AI siapSalin ke ChatGPT / Gemini, tampal jawapan semula.
✍️Isi borang automatikSubjek, tarikh, kelas, masa, SK, objektif, aktiviti & refleksi.

Cara pasang

Pilih peranti anda. Pemasangan hanya sekali sahaja (±3 minit).

  1. Pasang pelayar Microsoft EdgeDari Play Store (jika belum ada). Chrome Android tidak menyokong extension. ▶ Buka Play Store: Edge
  2. Tambah Tampermonkey dalam EdgeBuka Edge → tekan menu ☰ (bawah) → Extensions → cari Tampermonkey → tekan Get / Dapatkan.
    ☰ Menu
    🧩 Extensions
    Tampermonkey Get
  3. Buka halaman ini dalam EdgeSalin pautan halaman ini dan buka dalam Edge (bukan Chrome).
  4. Tekan "Pasang skrip"Tampermonkey akan buka halaman pemasangan → tekan Install. ⚡ Pasang skrip ERPH Autofill
    Tiada halaman Install keluar? Guna cara salin kod
    1. Tekan Salin kod di bawah.
    2. Edge ☰ → Extensions → Tampermonkey → Create a new script.
    3. Padam semua teks contoh → tekan lama → Paste → tekan ikon 💾 Save.
  5. Buka ERPH GURU di AppSheetBuka aplikasi ERPH GURU anda dalam Edge (log masuk seperti biasa). Butang ungu 📝 muncul di kiri bawah skrin. Siap! 🎉
  1. Pasang Tampermonkey dalam EdgeBuka kedai Edge Add-ons → tekan Get → Add extension. 🧩 Buka Tampermonkey (Edge Add-ons)
  2. Benarkan skrip pengguna (penting!)Taip edge://extensions di bar alamat → hidupkan Developer mode (kiri bawah) → klik Details pada Tampermonkey → hidupkan Allow user scripts.
    Developer mode
    Allow user scripts
    Tanpa langkah ini, butang 📝 tidak akan muncul.
  3. Tekan "Pasang skrip"Tab Tampermonkey akan terbuka → klik Install. ⚡ Pasang skrip ERPH Autofill
    Tiada halaman Install keluar? Guna cara salin kod
    1. Klik Salin kod.
    2. Klik ikon Tampermonkey (🧩 di toolbar) → Create a new script.
    3. Padam teks contoh → Ctrl+V → Ctrl+S.
  4. Buka ERPH GURU di AppSheetRefresh halaman AppSheet (F5). Butang ungu 📝 muncul di kiri bawah. Siap! 🎉

Cara guna (setiap minggu)

  1. Kali pertama: isi jadual waktuTekan 📝 → masukkan kelas, hari, masa & subjek anda. Tekan Muat senarai SK semasa borang ERPH dibuka supaya skrip kenal senarai SK.
  2. Buka borang ERPH baharuTekan 📝 → kelas seterusnya ditanda SETERUSNYA dengan SK dicadangkan ⭐.
  3. ① Salin Prompt → AITampal dalam ChatGPT / Gemini / Copilot dan salin jawapan (format JSON).
  4. ② Tampal jawapan → ③ Isi BorangSkrip isi semua medan. Semak, kemudian tekan Save sendiri.

🔒 Skrip tidak menekan butang Save dan tidak menyimpan kata laluan. Data jadual disimpan dalam pelayar anda sahaja.

Masalah biasa

Butang 📝 tak muncul

(1) Pastikan anda guna Edge, bukan Chrome. (2) Edge PC: semak Allow user scripts dihidupkan. (3) Buka Tampermonkey → pastikan ERPH Autofill (AppSheet) ada dan suisnya hidup. (4) Refresh AppSheet.

Ada medan keluar ✗ dalam log

Tekan butang Salin laporan ralat yang muncul, kemudian hantar melalui borang cadangan / WhatsApp. Kami akan betulkan.

Bagaimana kemas kini skrip?

Tampermonkey menyemak kemas kini secara automatik. Atau tekan semula Pasang skrip di halaman ini.

Perlu kod lesen?

Tidak. Edisi Bijak Mulia percuma sepenuhnya.
