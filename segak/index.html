SEGAK Injector

Isi skor SEGAK & BMI ke SPPB dengan 6 nombor setiap murid — termasuk autopilot sekelas yang isi, simpan dan teruskan ke murid seterusnya sendiri.

ℹ️ Untuk sistem SPPB (moeissppb.moe.gov.my) Berfungsi pada borang SEGAK di SPPB KPM. Anda masih log masuk SPPB seperti biasa — skrip hanya membantu mengisi borang.

Apa yang ia buat

📋Ambil kelasNama & MyID murid diambil terus dari halaman kelas.
⌨️6 nombor sahaja63 155 120 20 14 46 — berat, tinggi, NTB, TT, RTS, JM.
🤖AutopilotBuka murid, isi, Simpan, kembali, teruskan.
✅DisahkanSetiap murid disemak dengan popup "Berjaya!".

Cara pasang

Pilih peranti anda. Pemasangan hanya sekali sahaja.

  1. Pasang pelayar Microsoft EdgeDari Play Store (jika belum ada). Chrome Android tidak menyokong extension. ▶ Buka Play Store: Edge
  2. Tambah Tampermonkey dalam EdgeBuka Edge → menu ☰ (bawah) → Extensions → cari Tampermonkey → Get.
    ☰ Menu
    🧩 Extensions
    Tampermonkey Get
  3. Buka halaman ini dalam EdgeSalin pautan halaman ini dan buka dalam Edge.
  4. Tekan "Pasang skrip"Halaman Tampermonkey terbuka → tekan Install. ⚡ Pasang skrip SEGAK Injector
    Tiada halaman Install keluar? Guna cara salin kod
    1. Tekan Salin kod di bawah.
    2. Edge ☰ → Extensions → Tampermonkey → Create a new script.
    3. Padam semua teks contoh → tekan lama → Paste → ikon 💾 Save.
  5. Buka SPPBLog masuk moeissppb.moe.gov.my dalam Edge. Panel ⚡ SEGAK Injector muncul di bucu skrin. Siap! 🎉

Cara A — Extension

  1. Muat turun & ekstrakKlik kanan fail ZIP → Extract All. Simpan folder itu (jangan padam). ⬇️ Muat turun SEGAK Injector (ZIP, 41 KB)
  2. Buka halaman extensionTaip edge://extensions (atau chrome://extensions) di bar alamat → hidupkan Developer mode.
    Developer mode
  3. Load unpackedKlik Load unpacked → pilih folder yang diekstrak (folder yang ada fail manifest.json).
  4. Buka SPPBPanel ⚡ muncul. Jika tersembunyi, klik ikon SEGAK Injector di toolbar.

Cara B — Tampermonkey

  1. Pasang TampermonkeyDari kedai Edge Add-ons → Get. 🧩 Buka Tampermonkey (Edge Add-ons)
  2. Benarkan skrip penggunaedge://extensions → Developer mode → Details Tampermonkey → hidupkan Allow user scripts.
  3. Pasang skripKlik Install pada tab Tampermonkey yang terbuka. ⚡ Pasang skrip SEGAK Injector

Cara guna

  1. 📋 Ambil kelasBuka kad kelas di SPPB → panel tab Kelas → Ambil kelas dari halaman ini.
  2. ⌨️ Isi dataCari nama murid → taip 6 nilai (berat tinggi NTB TT RTS JM) → Enter. Ulang untuk murid lain.
  3. ▶ Suntik semuaAutopilot isi & simpan setiap murid. Tekan ■ Henti atau Esc untuk berhenti.

🔒 Cuba 1–2 murid dahulu dan semak di SPPB. Skrip tidak menyimpan kata laluan dan tidak menekan butang Hantar — semak & hantar sendiri.

Masalah biasa

Panel ⚡ tak muncul

(1) Guna Edge. (2) PC + Tampermonkey: pastikan Allow user scripts dihidupkan. (3) Pastikan skrip/extension dihidupkan. (4) Refresh SPPB (F5).

Nilai tak masuk ke borang

Pastikan suis Ditaksir dihidupkan pada borang SPPB. Kemudian cuba semula.

Perlu bayar / kod lesen?

Tidak. Semua ciri termasuk autopilot percuma sepenuhnya.
