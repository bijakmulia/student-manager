FOLDER ASET: DUNIA ILMU (open world 3D) — EduRank
====================================================

70 aset gambar. Semua prompt ada dalam PROMPT-ASET.txt (nombor, nama fail, nisbah, prompt).

CARA
 1. Jana gambar dengan prompt itu (Gemini / ChatGPT / lain-lain).
 2. Simpan dengan NAMA FAIL TEPAT (huruf kecil), contoh: ico_kayu.png  bg_tex_rumput.png  ani_harimau.png
 3. Letak dalam folder ini. Auto-push (setiap ~5 min) akan sendiri:
      - kemas nama fail, buang latar magenta (ikon/potret/gear/bangunan/kandang), potong ruang kosong
      - kecilkan saiz (tekstur 512, ikon 256, potret 512, langit 2048x1024 ...)
      - tukar bg_* kepada JPG, kemas kini senarai.json dan hantar ke GitHub
 4. Game guna gambar yang ada sahaja; yang belum ada guna ikon emoji / warna lalai.
    (Selepas gambar siap, minta Claude "pasang aset Dunia Ilmu" supaya game memakainya.)

PERIKSA: pastikan tekstur (bg_tex_*) tiada objek besar di tengah dan bersambung rata; langit tiada matahari.
